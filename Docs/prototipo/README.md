# Prototipo arquitectónico de SGO-Logic

Esta carpeta contiene el prototipo no funcional responsabilidad de la Persona 5 (Rol E), correspondiente al **Entregable 4** del enunciado.

| Artefacto | Descripción |
|---|---|
| [`mockups.html`](./mockups.html) | Wireframes del flujo principal: carrito en app móvil → pago en web → consulta de estado → devolución. Abrir directamente en el navegador. |

## Qué muestra

Cuatro pantallas estáticas que recorren el mismo pedido a través de canales distintos, ilustrando el escenario que motiva SGO-Logic (cita de la Directora de Comercialización: "no podemos tener silos"). Cada pantalla anota a qué CUN y EaC del DDA corresponde, para mantener trazabilidad entre el prototipo y las secciones 2, 6 y 9.

## Qué NO es

No hay lógica, backend, base de datos ni validaciones reales. Es un mockup de alto nivel según exige el enunciado ("no deben ser funcionales") — sirve para que el comité visualice la experiencia, no para demostrar una implementación.
